Install it

        
    
          
  1. Save the file as robots.txt (lowercase, plain text, UTF-8). Keep a backup of your current file first.
    2. 
          
  2. Upload it to the root of your domain so it loads at https://example.com/robots.txt. It must be at the root; a file in a subfolder is ignored.
    3. 
          
  3. Check it is live: open that URL in your browser and confirm you see the new rules. Crawlers may cache the old file for up to a day.
    4. 
          
  4. Validate: use a robots.txt tester such as the one in Google Search Console to confirm Googlebot is not accidentally blocked.
    5. 
        

        
GitHub Pages: put robots.txt in the root of the branch or folder that Pages publishes (often the repo root or /docs), commit and push. This only works if the site is served from the domain root: a custom domain, or a username.github.io site. A project site at username.github.io/repo/ cannot serve /robots.txt, so crawlers will never see it.

        
What this does and does not do. Well-behaved crawlers listed here may honour these rules. Crawlers that ignore robots.txt are unaffected. Blocking tokens like Google-Extended opts out of AI training but does not remove you from Google Search. Blocking AI search crawlers can remove you from those AI products.
