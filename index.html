AI Blocker

Upload a ZIP of a static website and get back a version that is harder for AI crawlers to read. Every page moves into a JavaScript file, only index.html and render.html stay as HTML, and a robots.txt asks the major AI crawlers to stay out. It all runs in your browser, so your files are never uploaded anywhere.

    What this does and does not do. Crawlers that do not run JavaScript only receive an empty page, and robots.txt is a request that well-behaved crawlers follow. Neither is a lock: some scrapers run JavaScript or ignore robots.txt, and anyone can still read your pages in their browser's developer tools. Visitors with JavaScript turned off see nothing.
